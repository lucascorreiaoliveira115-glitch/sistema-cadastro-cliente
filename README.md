# sistema-cadastro-cliente





\# Sistema de Cadastro de Clientes



Projeto desenvolvido para a atividade prática de

Gerenciamento de Configuração de Software.



\## Funcionalidades



\- Cadastro de clientes.

\- Listagem de clientes.

\- Busca de clientes.



\## Tecnologias utilizadas



\- Python

\- Git

\- GitHub



\## Objetivo



Desenvolver um sistema simples de cadastro de clientes,

utilizando o GitHub para controlar as versões dos arquivos.
